# AI-use disclosure and verification protocol

AI assistance is explicitly permitted in this portfolio, but outputs are not treated as authoritative.

## Material use in this release

| Work area | AI assistance | Human / deterministic verification required |
|---|---|---|
| Market research | Search-query expansion, source discovery, synthesis drafts | Open primary sources, confirm publication dates and figures, record URLs, reject unsupported extrapolation |
| Finance model | Formula review, model architecture suggestions, commentary drafting | Deterministic Decimal calculation, workbook formula checks, independent arithmetic and assumption review |
| Engineering | Code scaffolding, test ideas, documentation, refactoring review | Execute tests, inspect changed code, review access control, reproduce the commands locally |
| Public data | Web search to locate the audited filing and cross-check press figures; code to recompute ratios | Open the NSE filing, tick-check the headline figures by hand, treat undated marketplace prices as a rough range only, refresh the dated share price before quoting multiples |
| Business analysis | Requirement and acceptance-criteria drafting, traceability quality review | Validate workflow with actual participants; do not present generated personas or quotes as interviews |
| Product | PRD and experiment protocol drafting, event taxonomy critique | Real user discovery and task testing before claiming validation or adoption |
| Consulting | Storyline, issue-tree and slide critique | Reconcile every number, review source quality, challenge options and explain assumptions orally |

## Non-negotiable controls

- No confidential customer, employer, participant or personal data is entered into an external AI tool without explicit permission and an approved data-handling process.
- AI-generated numbers are not used as calculation results. Finance calculations come from code or workbook formulas.
- AI-generated citations are not accepted until the underlying source is opened and checked.
- No fabricated interviews, quotations, participant counts, UAT outcomes, management sign-offs, product usage, revenue recovery or time savings.
- Any AI-extraction feature remains out of production scope until a real use case, labelled evaluation dataset, critical-field metrics, human override and auditable error handling exist.

## Candidate readiness check

Before showing this project, the candidate should be able to explain: the formula for the ₹86.4 lakh pool; why ₹21.6 lakh is an assumption-led scenario; the 7.44-day residual; why estimator capacity is not cash; why the workbook does not include taxes and working capital in its monthly proxy; and what evidence would change the recommendation.
