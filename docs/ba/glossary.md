# Glossary

| Term | Meaning here |
|---|---|
| RFQ | Request for quotation from a customer. One RFQ has about 5 parts. |
| Cycle time | Working days from RFQ received to quote sent. |
| Touch time | Time someone is actually working on the RFQ. Costing is touch time. |
| Queue time | Time the RFQ waits for a person, a check or a decision. |
| Win-back | Share of lost RFQs that a faster quote would have won. 25% is an assumption. |
| Margin pool | Margin on all lost RFQs: 36 a year × ₹20 lakh × 12% = ₹86.4 lakh. A ceiling. |
| Estimator load | Hours of costing needed divided by hours estimators have. 78% today. |
| Erlang C | Queueing formula that gives the chance a new job must wait and the average wait. |
| Little's law | Average number in progress = arrival rate × average time in the system. |
| Funded gap | Delivery cost paid by the vendor minus cash received so far. |
| Cash received basis | Money counted on the day it arrives, not the day it is invoiced. |
| Gate | A formal check where the client approves before the next payment. |
| Early Release | The register, clock and upload, live before the full build. |
| Snapshot | The saved inputs, rate version and formula version behind a quote. |
| Parity | The tool's price equals the client's own Excel to ₹0.01 a line. |
| Working day | Elapsed weekday time divided by 24 hours. Weekends and listed holidays count zero. |
| P90 | The value 90% of RFQs come in under. |
| MDE | Smallest change a sample can reliably detect. |
| [Brief] [Derived] [Assumption] [Judgement] | Evidence tags. Given in the case, worked out, my estimate, my call. |
