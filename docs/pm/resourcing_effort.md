# Resourcing and effort estimate

**Purpose:** size the proposed 12-week discovery-to-pilot work. **Reader:** sponsor and hiring manager.

## Bottom-up method
Estimate each work package as person-days (PD). One PD = one person's planned work for one working day. These are planning estimates, not timesheets or vendor quotes.

| Work package | Role | PD |
|---|---|---:|
| Charter, schedule, gates, reporting | PM | 5 |
| AS-IS mapping and requirements | BA | 10 |
| Timestamp, loss-reason and data-quality review | Ops / BA | 10 |
| Financial model refresh and sensitivity | Finance | 6 |
| Product scope, journey and metrics | Product | 7 |
| Workflow configuration / light build | Product / IT | 18 |
| Security and access review | Security / IT | 5 |
| Test design and execution | QA / BA | 8 |
| Independent UAT and defect closure | Business tester / BA | 8 |
| Training and pilot support | Ops / PM | 8 |
| Pilot measurement and final decision | Finance / PM | 5 |
| **Total** |  | **90 PD** |

Add 15 PD management reserve (about 17% of base estimate) for rework, access delays and data cleaning. **Planning envelope = 105 PD.** Use a ±30% uncertainty range: 74–137 PD. Do not convert this to currency without approved role rates.

Peak concurrent demand is expected around build/test (Weeks 5–9). Avoid assuming every role is full-time. Confirm named availability before Gate 2.
