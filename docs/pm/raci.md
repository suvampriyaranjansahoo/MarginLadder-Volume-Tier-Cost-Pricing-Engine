# Project RACI

**RACI** means Responsible (does work), Accountable (owns the result), Consulted (gives input), Informed (receives updates). Exactly one Accountable role is assigned to each task.

| Task | Sponsor | PM | BA | Ops lead | Finance | Product/IT | Security | Business tester |
|---|---|---|---|---|---|---|---|---|
| Approve charter and scope | A | R | C | C | C | I | I | I |
| Baseline schedule and reporting | A | R | C | C | I | I | I | I |
| Map AS-IS process | I | C | A/R | R | C | I | I | C |
| Collect timestamps and loss reasons | I | C | R | A/R | C | I | I | I |
| Validate financial assumptions | I | C | C | C | A/R | I | I | I |
| Select option and approve Gate 1/2 | A | R | C | C | C | C | C | I |
| Define requirements and acceptance | I | C | A/R | R | C | C | C | C |
| Configure workflow | I | C | C | C | I | A/R | C | I |
| Review access and security controls | I | C | C | I | I | R | A | I |
| Execute technical/system tests | I | C | C | I | I | A/R | C | C |
| Execute business UAT | I | C | R | C | I | C | I | A/R |
| Approve pilot readiness Gate 3 | A | R | C | C | C | C | C | C |
| Run pilot and daily support | I | C | C | A/R | C | R | C | C |
| Evaluate benefits and scale/stop | A | R | C | C | R | C | C | C |
| Approve change to scope/budget/date | A | R | C | C | C | C | C | I |

RACI is a proposed role design. It does not identify real people or imply that anyone has accepted a role.
