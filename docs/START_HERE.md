# Recruiter walkthrough — start here

## Five-minute route
1. Read `docs/portfolio/one_minute_case_brief.md`.
2. Open `model/MarginLadder_Monthly_FP&A_Model.xlsx`.
3. Read `docs/finance/decision_bridge.md` for the recommendation and its financial logic.
4. Read `docs/finance/model_audit.md` for formulas, reconciliation and caveats.
5. Inspect the local app only if implementation detail is relevant to the interview.

## Choose one role lens
- **Finance Analyst (primary):** `docs/portfolio/role_paths/finance_analyst.md`
- Business Analyst: `docs/portfolio/role_paths/business_analyst.md`
- Associate Product Manager: `docs/portfolio/role_paths/apm.md`
- Consulting Analyst: `docs/portfolio/role_paths/consulting_analyst.md`

These are four ways to explain one coherent case, not four separate products.

## Interpret the metrics correctly
Every value is a case input, derived calculation, explicit assumption or synthetic demonstration. No customer outcomes are observed. The 4.9-month operating payback is pre-tax and before working capital; the cash model produces 23.6 months under additional assumptions.

## Demo
Install `requirements-dev.txt`, run `pytest`, then `uvicorn application.server:app --reload`. Local demo credentials are generated in a gitignored file. Do not use real customer or personal data.

## What this work sample demonstrates
It demonstrates business framing, deterministic financial modelling, workflow design, requirements and evidence discipline. It does not demonstrate customer adoption or realised commercial benefits.
